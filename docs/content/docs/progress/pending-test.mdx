# 待测试

- Agnes Image 2.0/2.1：文生图与带参考图编辑请求不应包含 `response_format`；应使用明确像素尺寸、顶层 `return_base64` 与 `image` 数组。1K、2K、4K 和常用比例应正确出图，8K 应明确提示不受支持。
- 生图取消：同时生成多张图片时，右键单个“生成中”槽位并选择“取消生成”，其余槽位应继续；取消卡片应可重试，记录中的成功、失败、取消数应准确，全取消后可立即再次生成。
- 响应式结果卡：全屏、普通非全屏及更窄窗口下，“添加到资产 / 加入参考图 / 下载”均应完整显示；空间不足时操作栏应自动换为两行且不溢出。
- 画布与节点插件：画布的节点、连线、撤销重做、生成流程和插件 `applyOps` 应继续正常工作；桌面启动后不得出现 Codex/Agent 面板、后台 Agent/Codex 进程或 17371 端口连接。
- 桌面打包：运行打包后，校验脚本应确认安装包不超过 180 MiB，且 `resources` 中不含 `canvas-agent` 或 `codex.exe`。
