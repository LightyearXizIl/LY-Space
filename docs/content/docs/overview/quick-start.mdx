# 快速开始

LY Space 仅提供 Windows 桌面端，所有数据和桌面能力均由本地应用管理。

## 安装

下载并运行 `LY Space Setup 0.0.2.exe`。覆盖安装会保留现有用户数据、应用 ID 和快捷方式名称。

## 本地构建

```bash
git clone git@github.com:LightyearXizIl/LY-Space.git
cd LY-Space
cd desktop
pnpm install
pnpm run pack:win
```

安装包输出到仓库的 `release/` 目录。

## 首次使用建议

- 先打开右上角配置弹窗，填入自己的 `Base URL`、`API Key` 和模型名。
- 如果需要提示词仓库内容，打开「提示词」会由桌面渲染层直连拉取并缓存到 IndexedDB。
- 如果需要跨设备同步画布、素材和生成记录，可在配置弹窗中填写 WebDAV。

## 说明

- 当前画布项目和“我的素材”主要保存在应用本地，WebDAV 同步需要用户自行配置。
- AI API Key 保存在应用本地，并由渲染层直接请求 OpenAI 兼容接口。
