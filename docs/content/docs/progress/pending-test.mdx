# 待测试

- 数据目录固定：换安装目录/更新软件后，`Data cache` 与 `Result` 保持固定在 `E:\Software\LY Space` 下，安装目录内不再出现这两个文件夹；旧版本数据（含 v0.0.9 浏览器数据）自动并入 E 盘。
- 生成结果自动落盘：生成图片/视频/文本/音频后，`E:\Software\LY Space\Result` 对应文件夹（Picture/Video/text/Audio）应立即出现文件；远程 http 图片不再出现「保存到本地目录失败」黄色提示。
- 取消生成：生成中的图片右键「取消生成」后，该卡片直接从结果区消失（其余槽位继续），生成记录的取消数准确。
- 结果图勾选批量操作：每张结果图左上角复选框可勾选；勾选后标题栏出现「已选 N 张 / 下载选中 / 添加资产 / 删除选中」；「全选」对所有成功结果图生效；下载选中逐张弹保存对话框。
- 保存/按钮稳定性：生成结果（含远程 http 图片）保存记录、加入参考图、添加到资产、下载均不再报「保存失败 / 加入参考图失败 / 添加到资产失败」；如仍报错请记录完整错误文案。
- 升级数据保留：安装新版（覆盖安装/自动更新）后，生图工作台之前的生成结果、生成记录应完整保留；首次启动新版会自动把旧安装目录下的缓存（IndexedDB）与结果文件迁移到 `E:\Software\LY Space\Data cache` / `E:\Software\LY Space\Result`。
- 结果详情与操作：生成图片右键「查看详情」在生成后立即可用（含无参考图时显示「暂无参考图」）；「下载 / 加入参考图 / 添加到资产」失败时均有明确提示；生成结果自动落盘到 `E:\Software\LY Space\Result` 对应文件夹。
- 生图工作台逻辑修复：查看历史记录不再改动生成参数（模型/质量/尺寸保持当前设置）；参考图最多 6 张、超限时提示并截取；删除记录时参考图缓存一并清理；生成完成但记录保存失败时会弹提示而非静默丢失。
- 生图工作台性能与恢复：生成过程中不再每秒写入会话（长任务时不卡顿），生成结束后重开软件仍能恢复最近一次的结果、输入与参考图。
- 生图尺寸与模型行为：3:1 比例搭配 1K 分辨率可正常生成；尺寸超限提示与实际限制一致；Gemini 模型手动填写像素尺寸（如 2048x2048）按该尺寸生成；使用带脚本的模型时选择蒙版编辑会提示不支持。
- 文本问答兼容性：使用忽略 stream 参数、直接返回 JSON 的 OpenAI 兼容代理时，问答仍能正常返回内容；SSE 中出现 ping 等非 JSON 行不再中断输出。
- 画布文本节点流式输出：使用 GRS / OpenAI 兼容 / Gemini 渠道生成文本节点时，流式内容应逐段累积完整显示，而不是只显示末尾片段（含插件 onDelta 回调）。
- 落盘提示：生成结果若为远程图片 URL 且拉取失败（或本地目录写入失败），应弹出全局存储错误提示。
- 生成结果保存目录：生成图片/视频/文本/音频后应立即自动保存到 `E:\Software\LY Space\Result` 下的 Picture/Video/text/Audio 四个文件夹（按类型对应）；旧版本升级后自动从原默认目录（安装目录/Result）切换到新目录；配置弹窗「结果保存目录」仍可修改并复制历史文件。
- 生图工作台结果右键：图片右击「查看详情」弹窗展示该图对应的提示词、参考图（可点大图）、模型/尺寸/质量/分辨率/耗时/大小等信息；右键「下载」同样走保存对话框。
- 生图工作台结果常驻：生成完成后关闭软件重开、或从生图工作台切到其他模块再切回，结果区图片、提示词与参考图均保留且可正常显示。
- 生图工作台结果区操作：「全选 / 删除 / 清除失败」按钮位于生成结果标题行，删除确认弹窗正常；左侧已无生成记录模块，无「新建 / 切换记录」入口。
- Agnes Image 2.0/2.1：文生图与带参考图编辑请求不应包含 `response_format`；应使用明确像素尺寸、顶层 `return_base64` 与 `image` 数组。1K、2K、4K 和常用比例应正确出图，8K 应明确提示不受支持。
- 生图取消：同时生成多张图片时，右键单个“生成中”槽位并选择“取消生成”，其余槽位应继续；取消卡片应可重试，记录中的成功、失败、取消数应准确，全取消后可立即再次生成。
- 响应式结果卡：全屏、普通非全屏及更窄窗口下，“添加到资产 / 加入参考图 / 下载”均应完整显示；空间不足时操作栏应自动换为两行且不溢出。
- 画布与节点插件：画布的节点、连线、撤销重做、生成流程和插件 `applyOps` 应继续正常工作；桌面启动后不得出现 Codex/Agent 面板、后台 Agent/Codex 进程或 17371 端口连接。
- 桌面打包：运行打包后，校验脚本应确认安装包不超过 180 MiB，且 `resources` 中不含 `canvas-agent` 或 `codex.exe`。
