# 新会话交接文档

> 用途：新 AI 会话接手前的快速上手指南。代码优先遵守 `AGENTS.md`，本文补充项目现状、关键决策与坑。

## 1. 项目概况

- **桌面 AI 创作工作台**：无限画布、生图工作台、视频创作台、精修工作台、提示词库、我的素材、配置
- **技术栈**：Electron（`desktop/main.cjs` 主进程 + `desktop/preload.cjs`）+ Vite + React 19 + TS + antd 6 + Tailwind 4 + Zustand；AI API 由**渲染进程直连** OpenAI 兼容接口（无后端）
- **代码结构**：
  - `desktop/main.cjs`：主进程（存储、IPC、自动更新、请求代理）
  - `desktop/preload.cjs` + `desktop/renderer/src/types/desktop.d.ts`：IPC 三端同步
  - `desktop/renderer/src/pages/`：image（生图）、video（视频）、canvas（画布）、refine（精修）、prompts（提示词库）、assets（我的素材）、config、home
  - `desktop/renderer/src/services/`：api/（各渠道请求）、image-storage、file-storage、desktop-storage（落盘）、oss-hosting、image-hosting（图床）、workbench-session
- **当前版本**：v0.3.3（`VERSION` 文件，tag `v0.3.3`）

## 2. 数据存储

| 项 | 默认位置 | 说明 |
|---|---|---|
| 生成结果文件 | `安装目录\Result\`（Picture/Video/text/Audio 四文件夹） | 生成后立即自动落盘 |
| 数据缓存（IndexedDB） | `安装目录\Data cache\` | 生成记录、结果、配置缓存；`sessionData` 指向它 |
| 存储配置 | `%APPDATA%\LY Space\app-data\storage-settings.json` | 用户可改 resultRoot/cacheRoot |
| 上次下载目录 | `%APPDATA%\LY Space\app-data\last-save-directory.txt` | 下载对话框默认沿用上次目录 |

- **存储策略（v0.2.7 起）**：**用户设置地址优先**——仅首次安装（无配置）默认跟随安装目录；用户设置过的结果/缓存目录（含历史 E 盘目录）一律保留，换目录安装不覆盖用户设置
- **升级保护**：`desktop/build/nsis-custom.nsh` 的 `customRemoveFiles` 宏（CopyFiles 跨卷安全）保证覆盖升级/自动更新时 `Data cache`、`Result` 不被 NSIS 卸载器清空
- **历史教训**：NSIS 升级会清空安装目录 → 数据曾放 E 盘（v0.1.5）→ v0.1.9 跟随安装目录 + NSIS 宏保护。**不要再把默认目录改回 E 盘**（用户自定义除外）

## 3. 关键链路与已修复的坑

### 3.1 图片生成与落盘（生图工作台 `pages/image/index.tsx`）
- **落盘**：API 返回 → `persistGeneratedImages`（`services/api/image.ts`）→ `fetchImageBlob`（浏览器 fetch 失败回退主进程 `lyspace:fetch-url`，绕过 CORS）→ `saveGeneratedBlob` → 主进程 `writeGeneratedOutput` 写文件并返回 `{ path, name }` → 图片记录 `localPath`
- **三条走 blob 的路径**（落盘/uploadImage 转存/下载）都必须用 `fetchImageBlob` 回退，别漏
- **删除同步本地**：`deleteSelectedImages` 只删除**勾选的图片**（v0.2.5 修复：不再误删同批次其他图），日志中移除被删图（无剩余才删记录），blob（storageKey）与本地文件（localPath）同步回收；主进程删除失败自动重试 3 次，结果有明确提示
- **切换页面不中断**（v0.2.2）：生成任务存模块级 `activeImageTasks`（Map + 订阅），组件卸载不 abort；返回页面时合并任务表恢复状态，仅真实重启才标 failed
- **结果图交互**：右键菜单（查看详情/重新编辑/下载）、左上角勾选（全选/下载选中/添加资产/删除选中，删除走最右「删除」按钮）、生成中卡片**仅右击取消生成**（v0.2.4 回退点击取消）

### 3.2 视频生成（视频创作台 `pages/video/index.tsx` + `services/api/video.ts`）
- **任务式生成**：`createVideoGenerationTask` 提交 → `pollVideoGenerationLog` 轮询（Seedance 5s / Agnes 10s / 其他 2.5s）→ `storeGeneratedVideo` 落盘 `Result\Video`（fetch 跨域失败回退主进程 `fetchUrl`）
- **轮询限流**：Agnes 状态查询遇 429/rate limit 返回 pending 继续轮询，不中断
- **切换页面**：轮询闭包后台继续，`activeVideoLogIds` 模块级防重复轮询，任务完成通知（`emitVideoTaskUpdate`）刷新新挂载页面
- **Agnes 参考图**（图生视频）：要求公网 HTTPS 图片 URL——自动托管链路：**阿里云 OSS（已配置时）→ 免费图床（uguu.se → tmpfiles.org → catbox.moe）→ 全部失败明确报错引导**；上传前统一转 PNG/JPEG + 最长边 1024 压缩；浏览器直传失败回退主进程代理（`lyspace:upload-free-host`）
- **Agnes API 路径（官方文档 agnes-video-v20）**：Base URL `https://api.agnes-ai.cn`（中国站）/ `https://apihub.agnes-ai.com`（国际站）；创建任务 `POST /v1/videos`（`buildApiUrl` 自动补 `/v1`）、结果查询 `GET /agnesapi?video_id=`（`pollAgnesVideoTask` 已剥 `/v1`）
- **请求代理回退**（v0.3.0）：`agnesRequest` 网络层失败（CORS/连接/超时）自动回退主进程 `lyspace:proxy-request` 重试；错误提示区分：HTML 响应=Base URL 填成网页地址、litellm/UploadFile=Agnes 服务端异常（可能维护中）

### 3.3 公共设施
- **IPC**：`lyspace:fetch-url`、`save-file-dialog`、`save-files-dialog`（批量一次弹窗）、`write-generated-output`、`delete-generated-files`、`upload-free-host`、`proxy-request`、`storage-settings`、更新相关等——**均需 main.cjs + preload.cjs + desktop.d.ts 三端同步**
- **自动更新**：启动自动 `checkForUpdates`（来源 `auto`）；**仅启动自动检查发现新版本时弹居中弹窗**（`UpdatePrompt`，含版本号/更新日志/下载按钮/下载进度/重启安装）；关于页手动检查（来源 `manual`）不弹窗，仅在页内显示状态与日志。来源标记：`checkForUpdate(source)` → `updateState.triggeredBy`（`update-available` 时写入，三端同步）。**CI 发布时自动把 CHANGELOG 段落写入 Release 说明**（`--notes` 从 `$env:GITHUB_WORKSPACE\CHANGELOG.md` 提取）
- **优化提示词**（生图/视频工作台）：TextArea 下方 ModelPicker（capability=text，默认 gpt-5.5）+ Wand2 按钮，`requestImageQuestion` 流式回填
- **参考图**：支持点击放大（Image.PreviewGroup）、左右排序（ReferenceOrderButtons）、上传/框内粘贴/公网 URL、清空按钮（各类型独立）；参考视频/音频同样有清空按钮
- **CI 坑**：`git add -u` 不含新文件——新增文件必须显式 `git add`；`publish-desktop.yml` 发布步骤依赖 `GITHUB_WORKSPACE` 绝对路径（勿改回相对路径）

### 3.4 v0.3.2 变更要点

- **渠道启用/关闭开关**（配置页渠道列表最左侧 Switch）：`ModelChannel.enabled?: boolean`（缺省视为启用）。**坑**：persist merge 走 `createModelChannel`（显式对象构造会丢弃未列出的字段），新增渠道字段必须同步加进 `createModelChannel`（`enabled: channel?.enabled !== false`）。禁用生效点：`selectableModelsByCapability`/`selectableImageModelsByFeature` 过滤禁用渠道、`resolveModelChannel` 回退第一个启用渠道、`finishConfig` ready 只统计启用渠道。
- **参考图框内粘贴**：image/video 工作台移除"剪切板"按钮；参考图容器 `tabIndex + onMouseEnter focus + onPaste`，`addReferencesFromPaste` 从 `clipboardData.items` 提取 image/* 文件（无需权限弹窗），无图静默忽略；`addReferences` 参数放宽为 `FileList | readonly File[]`。
- **Agnes 视频对齐官方文档**：高级参数（帧率/种子/推理步数/负面提示词）仅 Agnes 渠道面板显示；请求补发 `frame_rate`/`seed`/`negative_prompt`/`num_inference_steps`/顶层 `mode`；`video_id` 优先查询；`auto` 尺寸不发宽高；帧数按帧率联动（8n+1/≤441）；秒数上限 18、默认横屏 1152x768。

### 3.5 v0.3.3 变更要点

- **移除个人词库**：`PERSONAL_SOURCE_ID`、`personal-prompts.ts`、`personal-prompt-editor-dialog.tsx` 及相关 UI（新增/编辑/删除/一键加入）全部删除，提示词库恢复纯远程来源。
- **资产选择器双按钮**（`asset-picker-modal.tsx`）：卡片去掉整卡点击插入与 hover"插入"覆盖层，底部新增"复制"（text 复制内容 / image 复制 dataUrl / video 复制 url）与"插入"按钮。
- **更新日志显示**（`about-panel.tsx`）：无新版本时 Timeline 显示当前版本（`APP_VERSION`）日志；检查到新版本（`hasNewVersion`）后显示最新版本日志。
- **启动自动检查弹窗**（重新引入 `UpdatePrompt`）：`updateState.triggeredBy` 区分来源——`auto`（启动自动检查）弹居中 Modal（版本号/更新日志/下载/进度/重启安装，同版本只弹一次）；`manual`（关于页手动）不弹窗。

## 5. 发版本流程（用户要求"更新版本/发版本"时）

1. **更新交接文档**（本节）：版本号改 vX.Y.Z；新增小节记录 vX.Y.Z 变更要点与坑；用户偏好按需补充
2. `CHANGELOG.md`：Unreleased 整理成 `## vX.Y.Z - 日期`，保留空 Unreleased
3. `VERSION` → vX.Y.Z；`desktop/package.json`、`desktop/renderer/package.json` version 同步
4. `node desktop/scripts/verify-release-version.cjs vX.Y.Z` 校验
5. `git add -u`（**新文件要显式 add**）+ commit `release: vX.Y.Z` + `git tag vX.Y.Z`
6. `git push origin main` + `git push origin vX.Y.Z` —— tag 触发 CI（`publish-desktop.yml`），自动构建上传并**写入 Release 日志**
7. 用 `git credential fill` 取 token 验证 CI `completed/success` + release 资产（exe/blockmap/latest.yml 齐全 + body 非空）
8. 本地 `pnpm --dir desktop run pack:win` 留存安装包到 `release/`（用户习惯）
9. 注意：改版本号重发需删旧 tag/release（force push main + tag），参考 v0.2.0/v0.3.0 处理
