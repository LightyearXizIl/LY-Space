# 新会话交接文档

> 用途：新 AI 会话接手前的快速上手指南。代码优先遵守 `AGENTS.md`，本文补充项目现状、关键决策与坑。

## 1. 项目概况

- **桌面 AI 创作工作台**：无限画布、生图工作台、视频创作台、精修工作台、提示词库、我的素材、配置
- **技术栈**：Electron（`desktop/main.cjs` 主进程 + `desktop/preload.cjs`）+ Vite + React 19 + TS + antd 6 + Tailwind 4 + Zustand；AI API 由**渲染进程直连** OpenAI 兼容接口（无后端）
- **代码结构**：
  - `desktop/main.cjs`：主进程（存储、IPC、自动更新、请求代理）
  - `desktop/preload.cjs` + `desktop/renderer/src/types/desktop.d.ts`：IPC 三端同步
  - `desktop/renderer/src/pages/`：image（生图）、video（视频）、canvas（画布）、refine（精修）、prompts（提示词库）、assets（我的素材）、config、home
  - `desktop/renderer/src/services/`：api/（各渠道请求）、image-storage、file-storage、desktop-storage（落盘）、oss-hosting、image-hosting（图床）、workbench-session
- **当前版本**：v0.3.6（`VERSION` 文件，tag `v0.3.6`）

## 2. 数据存储

| 项 | 默认位置 | 说明 |
|---|---|---|
| 生成结果文件 | `安装目录\Result\`（Picture/Video/text/Audio 四文件夹） | 生成后立即自动落盘 |
| 数据缓存（IndexedDB） | `安装目录\Data cache\` | 生成记录、结果、配置缓存；`sessionData` 指向它 |
| 存储配置 | `%APPDATA%\LY Space\app-data\storage-settings.json` | 用户可改 resultRoot/cacheRoot |
| 上次下载目录 | `%APPDATA%\LY Space\app-data\last-save-directory.txt` | 下载对话框默认沿用上次目录 |

- **存储策略（v0.2.7 起）**：**用户设置地址优先**——仅首次安装（无配置）默认跟随安装目录；用户设置过的结果/缓存目录（含历史 E 盘目录）一律保留，换目录安装不覆盖用户设置
- **升级保护**：`desktop/build/nsis-custom.nsh` 的 `customRemoveFiles` 宏（CopyFiles 跨卷安全）保证覆盖升级/自动更新时 `Data cache`、`Result` 不被 NSIS 卸载器清空
- **历史教训**：NSIS 升级会清空安装目录 → 数据曾放 E 盘（v0.1.5）→ v0.1.9 跟随安装目录 + NSIS 宏保护。**不要再把默认目录改回 E 盘**（用户自定义除外）

## 3. 关键链路与已修复的坑

### 3.1 图片生成与落盘（生图工作台 `pages/image/index.tsx`）
- **落盘**：API 返回 → `persistGeneratedImages`（`services/api/image.ts`）→ `fetchImageBlob`（浏览器 fetch 失败回退主进程 `lyspace:fetch-url`，绕过 CORS）→ `saveGeneratedBlob` → 主进程 `writeGeneratedOutput` 写文件并返回 `{ path, name }` → 图片记录 `localPath`
- **三条走 blob 的路径**（落盘/uploadImage 转存/下载）都必须用 `fetchImageBlob` 回退，别漏
- **删除同步本地**：`deleteSelectedImages` 只删除**勾选的图片**（v0.2.5 修复：不再误删同批次其他图），日志中移除被删图（无剩余才删记录），blob（storageKey）与本地文件（localPath）同步回收；主进程删除失败自动重试 3 次，结果有明确提示
- **切换页面不中断**（v0.2.2）：生成任务存模块级 `activeImageTasks`（Map + 订阅），组件卸载不 abort；返回页面时合并任务表恢复状态，仅真实重启才标 failed
- **结果图交互**：右键菜单（查看详情/重新编辑/下载）、左上角勾选（全选/下载选中/添加资产/删除选中，删除走最右「删除」按钮）、生成中卡片**仅右击取消生成**（v0.2.4 回退点击取消）

### 3.2 视频生成（视频创作台 `pages/video/index.tsx` + `services/api/video.ts`）
- **任务式生成**：`createVideoGenerationTask` 提交 → `pollVideoGenerationLog` 轮询（Seedance 5s / Agnes 10s / 其他 2.5s）→ `storeGeneratedVideo` 落盘 `Result\Video`（fetch 跨域失败回退主进程 `fetchUrl`）
- **轮询限流**：Agnes 状态查询遇 429/rate limit 返回 pending 继续轮询，不中断
- **切换页面**：轮询闭包后台继续，`activeVideoLogIds` 模块级防重复轮询，任务完成通知（`emitVideoTaskUpdate`）刷新新挂载页面
- **Agnes 参考图**（图生视频）：要求公网 HTTPS 图片 URL——自动托管链路：**阿里云 OSS（已配置时）→ 免费图床（uguu.se → tmpfiles.org → catbox.moe）→ 全部失败明确报错引导**；上传前统一转 PNG/JPEG + 最长边 1024 压缩；浏览器直传失败回退主进程代理（`lyspace:upload-free-host`）。**OSS 配置与公网 URL 入口在配置对话框「阿里云设置」Tab（v0.3.4 起，原视频页按钮已移除）**；公网 URL 经 `reference-handoff`（`url` 字段）+ `lyspace:reference-handoff-created` 事件即时加入视频创作台参考图
- **Agnes API 路径（官方文档 agnes-video-v20）**：Base URL `https://api.agnes-ai.cn`（中国站）/ `https://apihub.agnes-ai.com`（国际站）；创建任务 `POST /v1/videos`（`buildApiUrl` 自动补 `/v1`）、结果查询 `GET /agnesapi?video_id=`（`pollAgnesVideoTask` 已剥 `/v1`）
- **请求代理回退**（v0.3.0）：`agnesRequest` 网络层失败（CORS/连接/超时）自动回退主进程 `lyspace:proxy-request` 重试；错误提示区分：HTML 响应=Base URL 填成网页地址、litellm/UploadFile=Agnes 服务端异常（可能维护中）

### 3.3 公共设施
- **IPC**：`lyspace:fetch-url`、`save-file-dialog`、`save-files-dialog`（批量一次弹窗）、`write-generated-output`、`delete-generated-files`、`upload-free-host`、`proxy-request`、`storage-settings`、更新相关等——**均需 main.cjs + preload.cjs + desktop.d.ts 三端同步**
- **自动更新**：启动自动 `checkForUpdates`（来源 `auto`）；**仅启动自动检查发现新版本时弹居中弹窗**（`UpdatePrompt`，含版本号/更新日志/下载按钮/下载进度/重启安装）；关于页手动检查（来源 `manual`）不弹窗，仅在页内显示状态与日志。来源标记：`checkForUpdate(source)` → `updateState.triggeredBy`（`update-available` 时写入，三端同步）。**CI 发布时自动把 CHANGELOG 段落写入 Release 说明**（`--notes` 从 `$env:GITHUB_WORKSPACE\CHANGELOG.md` 提取）
- **优化提示词**（生图/视频工作台）：TextArea 下方 ModelPicker（capability=text，默认 gpt-5.5）+ Wand2 按钮，`requestImageQuestion` 流式回填
- **参考图**：支持点击放大（Image.PreviewGroup）、左右排序（ReferenceOrderButtons）、上传/框内粘贴/公网 URL（阿里云设置 Tab 添加）、清空按钮（各类型独立）；参考视频/音频同样有清空按钮
- **CI 坑**：`git add -u` 不含新文件——新增文件必须显式 `git add`；`publish-desktop.yml` 发布步骤依赖 `GITHUB_WORKSPACE` 绝对路径（勿改回相对路径）

### 3.7 流畅度优化（v0.3.5）

- **画布编辑持久化防抖**：nodes/connections/chatSessions 保存走 500ms trailing debounce（`projectSaveTimerRef` + `pendingProjectSaveRef`），拖拽/生成不再每帧全量 JSON.stringify + IndexedDB 写；切换项目/卸载时 `flushProjectSave` 立即落盘。**坑**：新加画布持久化字段时确认走 pending patch 闭包，勿直接调用 updateProject 高频路径。
- **缩放不重渲染节点**：新建 `useCanvasViewportStore`（`stores/canvas/use-canvas-viewport-store.ts`）保存当前 viewport；`CanvasNode` 移除 scale prop（zoom 不再击穿 React.memo），节点内经 `store.getState().viewport.k` 读取（resize 开始时快照进 resizeRef）。**坑**：该 store 仅供 getState 读取，不要用 selector 订阅（会失去 memo 收益）。
- **rAF 合并**：滚轮缩放（`infinite-canvas.tsx`，基于 viewportRef 累积保证精度）、框选、连线拖拽、refine 预览重绘均 rAF 合并，每帧最多一次 setState。
- **memo 化**：ConnectionPath（pathD useMemo，onSelect/onContextMenu 必须传稳定引用 `handleSelectConnection`/`handleConnectionContextMenu`）、CanvasTopBar/CanvasToolbar/CanvasZoomControls/CanvasSidePanel（内联箭头回调已提升为稳定 useCallback）、PromptCard（onOpen/onCopy/extraAction 需稳定引用，`prompts/index.tsx` 已 useCallback）。
- **高频写库修复**：video 页 `saveWorkbenchSession` 依赖去掉 elapsedMs（对齐 image 页既有先例，elapsedMs 取闭包最新值）；refine 会话保存 500ms 防抖（`sessionSnapshotRef` 渲染期同步 + 卸载 flush）；refine 调色/LUT Slider 改 onChange 轻量预览、onChangeComplete 才 commitEdits（history 不再每帧 push）。
- **输入框失焦提交**：新建 `useDraftInput`（`hooks/use-draft-input.ts`）+ video 面板输入组件本地 draft 模式，配置弹窗 8 处与设置面板输入不再每键写全局 config store（避免全量 persist 序列化 + 订阅者重渲染），失焦/Enter 提交。**坑**：受控输入必须本地草稿否则输入回跳；外部配置变化（导入）经 value 依赖自动回显。
- **图片加载**：assets 封面 `loading="lazy" decoding="async"`；画布节点 img `decoding="async"`。

### 3.9 v0.3.5 节点悬浮工具条自动换行

- **工具条换行**（`canvas-node-hover-toolbar.tsx`）：容器去掉固定 `h-12`，改 `flex flex-wrap justify-center gap-y-1` + `max-w-[calc(100vw-32px)]`——图片节点全工具（原约 1300px 单行）超过视口宽度自动折为两行；短工具条（文本节点）仍单行。**坑**：absolute flex 容器不加 `max-w` 时宽度收缩到内容、`flex-wrap` 不生效；按钮内部 `whitespace-nowrap` 保持不折行，换行是工具条级。

### 3.10 v0.3.6 更新下载断点续传与弹窗改造

- **自研断点续传下载器**（`desktop/main.cjs`）：保留 electron-updater 的版本检查（`update-available` 事件缓存 `files[0]` 的 url/sha512/size），下载改为 `net.request` + `Range: bytes=N-` 续传写 `userData/updates/<文件名>.part`，暂停保留 `.part`（`pauseUpdateDownload` → abort + flush，状态 `paused`），继续调用 `downloadUpdate()` 自动从断点续传；完成后 sha512（base64 去 padding）校验，通过才改名为 `.exe` 进入 `downloaded`，校验失败删 `.part` 报错。
- **安装方式变更**：`requestUpdateInstall` 不再用 `autoUpdater.quitAndInstall`，改为 `persistence-flushed` 后 `spawn(安装器, ["/S", `/D=${path.dirname(app.getPath("exe"))}`])` + `app.quit()`（NSIS 静默安装到当前安装目录，`runAfterFinish` 自动重启应用）。**坑**：`/D=` 必须作为最后一个整体参数（含空格路径）；下载文件 URL 拼 `https://github.com/LightyearXizIl/LY-Space/releases/download/<tag>/<files[0].url>`（tag 带 v，文件名不带 v）。
- **三端同步**：IPC `lyspace:cancel-update-download` → `lyspace:pause-update-download`（`pauseUpdateDownload`）；`AppUpdateStatus` 新增 `"paused"`（desktop.d.ts + 主进程状态机）。
- **弹窗**（`update-prompt.tsx`）：`styles.wrapper` flex 强制正中心（替代仅 `centered`）；`maskClosable={false}` `keyboard={false}`；`open` 覆盖 available/downloading/paused/downloaded/error（下载失败、暂停均驻留，仅「稍后」关闭）；下载中「暂停」、暂停后「继续下载」+「稍后」、失败显示错误 +「重试」。
- **关于页**（`about-panel.tsx`）：下载中「取消下载」→「暂停」；`paused` 显示「已暂停 x / y」+「继续下载」；检查按钮 disabled 适配 paused。

### 3.11 v0.3.6 关闭最小化到系统托盘

- **关闭行为**（`desktop/main.cjs`）：`mainWindow.on("close")` 中 `allowWindowClose` 为 false 时 `preventDefault()` + `mainWindow.hide()`——点右上角 X 只隐藏到系统托盘，不退出；数据由现有防抖/异步落盘持续保存（隐藏不触发 flush）。
- **系统托盘**：`createTray()`（whenReady 末尾调用）：图标 `build/icon.png` resize 32×32，tooltip「LY Space」，**左键单击**显示主界面（show/restore/focus），**右键菜单**：显示主界面 / 关闭。
- **托盘「关闭」= flush 后退出**：菜单「关闭」发送 `lyspace:flush-persistence` → 渲染进程落盘 → `persistence-flushed` → `allowWindowClose=true` → `mainWindow.close()` 真退出（复用既有流程，数据安全）。
- **second-instance**：`!mainWindow.isVisible()` 时先 `show()` 再 focus（窗口隐藏时再次启动实例恢复显示）。
- **坑**：① `tray` 必须是模块级引用（局部变量会被 GC 导致图标消失）；② 隐藏 ≠ 退出，不要再在 close 里发 flush（托盘关闭才走 flush 流程）；③ `closingTimer` 10 秒等待警告已随旧 close 流程移除。

### 3.8 缩略图管线与提示词虚拟滚动（v0.3.5）

- **缩略图管线**：新建 `services/thumbnail.ts`——`getThumbnailUrl(source)` 把 blob:/data: URL 原图降采样为最长边 1024 的 JPEG object URL（`createImageBitmap` + canvas + `toBlob`），模块级 LRU 缓存 200 条（淘汰时 revoke），并发上限 3（`runThumbnailTask` 队列），失败返回 null 由调用方回退原图。
  - **画布图片节点**（`canvas-node.tsx` ImageContent）：默认显示缩略图；订阅 `useCanvasViewportStore.viewport.k`（仅本子组件重渲染，CanvasNode memo 外壳不受影响），当 `节点宽 × 缩放 > 1024×1.2` 时切回原图避免放大模糊。**坑**：缩略图 URL 是共享缓存，组件切换时不可 revoke（LRU 淘汰才 revoke）；图片内容变化（新 blob URL）自动走新 key，旧条目由 LRU 回收。
  - **assets 封面**（`pages/assets/index.tsx` AssetCard）：同样走缩略图，生成失败回退原图。
- **提示词虚拟滚动**（`pages/prompts/index.tsx`）：引入 `@tanstack/react-virtual`，按窗口断点（1280px→3 列 / 640px→2 列 / 其余 1 列）把卡片分组成行，行虚拟化 + 动态测量（`measureElement`），overscan 4，滚动容器为原 `<main>`（`scrollRef`）；无限滚动加载（`handleListScroll` 滚到底 fetchNextPage）保留不变；`PromptGrid` 组件已删除。**坑**：行高由封面（aspect 4:3 固定）+ 内容决定，首次渲染即稳定，动态测量一次后不再漂移；resize 跨断点会重新分组，滚动位置可能有轻微偏移（可接受）。

## 5. 发版本流程（用户要求"更新版本/发版本"时）

1. **更新交接文档**（本节）：版本号改 vX.Y.Z；新增小节记录 vX.Y.Z 变更要点与坑；用户偏好按需补充
2. `CHANGELOG.md`：Unreleased 整理成 `## vX.Y.Z - 日期`，保留空 Unreleased
3. `VERSION` → vX.Y.Z；`desktop/package.json`、`desktop/renderer/package.json` version 同步
4. `node desktop/scripts/verify-release-version.cjs vX.Y.Z` 校验
5. `git add -u`（**新文件要显式 add**）+ commit `release: vX.Y.Z` + `git tag vX.Y.Z`
6. `git push origin main` + `git push origin vX.Y.Z` —— tag 触发 CI（`publish-desktop.yml`），自动构建上传并**写入 Release 日志**
7. 用 `git credential fill` 取 token 验证 CI `completed/success` + release 资产（exe/blockmap/latest.yml 齐全 + body 非空）
8. 本地 `pnpm --dir desktop run pack:win` 留存安装包到 `release/`（用户习惯）
9. 注意：改版本号重发需删旧 tag/release（force push main + tag），参考 v0.2.0/v0.3.0 处理
